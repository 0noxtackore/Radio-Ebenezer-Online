# Documentation

Welcome to the **Radio Ebenezer** documentation. This folder collects English-language guides for setup, usage, and troubleshooting.

## Contents

- **SETUP.md** — how to run the project locally.
- **USAGE.md** — how to use the web radio UI and main features.
- **TROUBLESHOOTING.md** — common issues and fixes.

## Quick overview

- The app is a static web project (HTML/CSS/JS).
- The streaming URL is configured in `js/app.js` (`STREAM_URL`).
- UI styles live in `css/styles.css`.
- The main entry is `index.html`.

If you need Spanish docs, keep a separate copy under a different filename.
