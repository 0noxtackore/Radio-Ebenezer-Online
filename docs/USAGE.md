# Usage

## Home / Player

- Tap the play button to start the live stream.
- The status text and dot show playback state.
- The cover disc animates while playing.

## Calendar

- The calendar highlights fixed weekly events:
  - **Culto en vivo** (Sunday 9:00 AM)
  - **Culto de oración** (Monday–Friday 3:00 PM)
  - **Predicación especial** (daily 6:00 PM)

## Notifications

- The notifications screen shows today’s relevant events.
- Each card includes the event day, time, and a countdown (h m s).

## Offline & Server Alerts

- If the device goes offline, an overlay warns the user and pauses playback.
- If the stream server fails while online, a server alert is shown with a patience verse.
- When the server comes back, the app reloads automatically.
